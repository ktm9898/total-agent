# Total-Agent (서울신용보증재단 센터 멀티 AI 에이전트 시스템)

> **비서실장 동적 오케스트레이션 기반 5대 실무팀(리서치 · 기획 · 감사 · 운영 · 미디어) 자율 공방 시스템**  
> 고정된 단일 파이프라인이 아니라, **비서실장(Chief Secretary)**이 센터장의 지시 의도를 사전 확인하고 과업 성격에 맞춰 **참여 팀·순서·3대 산출물(보고서·요약서·보도자료)**을 동적으로 편성·조율하는 의사결정 보좌 플랫폼입니다.

---

## ✨ 핵심 기능 및 UI/UX 아키텍처

### 1. 비서실장 주도형 동적 라우팅 & 1회 사전 의도 확인
* **간결한 2단계 과제 하달 (`+ 신규과제`)**:
  1. **과제명 입력**: 센터장이 주제를 입력하면 비서실장이 1차로 과업 성격을 분석합니다.
  2. **비서실장 확인 (단 1회 질문)**: 하위 5개 팀을 일제히 호출하기 전에, 비서실장이 모달 내에서 핵심 방향 선택지(지원 방향, 연계 조건, 대응 기조 등)를 간결하게 확인하여 불필요한 API 재호출을 방지합니다 (`일임 실행`으로 즉시 생략 가능).
* **과업 유형별 맞춤형 팀 편성**:
  * **신사업·특례보증 기획**: `리서치팀 ➔ 기획팀 ➔ 감사팀 ➔ 운영팀 ➔ 비서실장 ➔ 미디어팀` (전원 가동)
  * **시의회·본부 감사 대응**: `리서치팀 ➔ 감사팀 ➔ 운영팀 ➔ 비서실장`
  * **창구 심사·절차 개선**: `리서치팀 ➔ 운영팀 ➔ 감사팀 ➔ 비서실장 ➔ 미디어팀`
  * **대내외 동향 브리핑**: `리서치팀 ➔ 비서실장 ➔ 미디어팀`

### 2. 1단 와이드 테이블 & 모달 중심의 직관적 3대 뷰
불필요한 부연 설명과 복잡한 2단 분할을 제거하고, 한눈에 들어오는 **1단 전체폭 테이블 + 상세 모달** 구조로 설계했습니다.
* **현황판 (`Dashboard`)**:
  * **1층**: `+ 신규과제` 버튼 및 `전체과제` · `결재대기` · `결재완료` 현황 카드
  * **2층**: 6개 에이전트 팀 카드 (팀명, 가동 상태 점, 할당 AI 모델명 표시 / 클릭 시 해당 팀 집무실로 이동)
  * **3층**: 최근 과제 최대 5건 요약 테이블 (`일자` | `지시과업` | `상태` | `산출물`)
* **팀 집무실 (`Team Rooms`)**:
  * 6개 팀(`비서실장`, `리서치팀`, `기획팀`, `감사팀`, `운영팀`, `미디어팀`) 개별 작업 내역 조회 (`일자` | `지시과업` | `단계` | `결과요약`)
  * **`팀 설정` 모달**: 팀별 AI 엔진(모델) 지정, 참고 데이터셋 연결, **팀 업무지침서(`prompts/*.md`) 직접 편집 및 GitHub 실시간 커밋** 지원
* **히스토리 (`Archive`)**:
  * 결재 완료된 모든 과제를 영구 보관 및 검색 (`일자` | `유형` | `지시과업` | `상태` | `산출물`)

### 3. 3대 표준 산출물 (SVG 컬러/흑백 아이콘) & 실시간 AI 회의록
* **SVG 벡터 아이콘 산출물 표시**:
  * 테이블의 `산출물` 열에 한글 텍스트나 이모지 없이 **보고서 · 요약서 · 보도자료** 3종을 SVG 아이콘 버튼으로 표시합니다.
  * 해당 과제에서 생성된 산출물은 **컬러 활성 아이콘**, 생성 대상이 아닌 산출물은 **흑백 비활성 아이콘**으로 즉시 구분됩니다.
* **리포트 & 보도자료 전용 문서 서식**:
  * **보고서 · 요약서**: `ai_news_briefing` 인사이트 리포트와 동일한 타이포그래피·여백·인쇄 규격(`.report-content`) 적용
  * **보도자료**: 동일한 기본 여백·글꼴 위에 공공기관 보도자료 전용 상단 배너(`보 도 자 료`), 배포일시·담당부서 메타 테이블, 메인·서브 헤드라인 박스 적용
* **실시간 AI 합동 회의록 (`회의록` 탭)**:
  * 각 팀 에이전트가 팩트 발제, 레드팀 반박(감사팀), 현장 병목 역제안(운영팀), 최종 절충(비서실장)을 주고받은 실제 의사결정 대화를 그대로 열람할 수 있습니다.

### 4. 보안 아키텍처 (GAS 시크릿 금고 & Read-Only 연동)
* **API Key 무노출 원칙**: Google, Anthropic, OpenAI 등 AI 공급자별 API Key는 브라우저 로컬 스토리지에 저장하지 않고 **Google Apps Script (GAS) `Script Properties` 또는 GitHub Secrets**에 보관하여 프록시 방식으로 호출합니다.
* **기구축 레포지토리 100% Read-Only 참조**:
  1. **`ai_news_briefing`**: 일일 소상공인 뉴스 요약 및 인사이트 리포트 읽기 전용 조회
  2. **`meeting_copilot`**: 주간 회의록 5열 지식 DB 메타데이터 스캔 및 원문 핀셋 조회

```text
total-agent/

│   ├── team_planning.md           # 기획팀 업무지침서
│   ├── team_audit.md              # 감사팀 업무지침서
│   ├── team_operations.md         # 운영팀 업무지침서
│   └── team_media.md              # 미디어팀 업무지침서
│
├── connectors/                    # 외부 데이터셋 Read-Only 어댑터 및 비식별화 모듈

│   ├── meeting_client.py          # meeting_copilot 조회 클라이언트

│
└── web/
    └── index.html                 # 루트 index.html과 동기화된 웹 대시보드
```
