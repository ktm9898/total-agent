# SCGF Total-Agent (서울신용보증재단 센터 멀티 AI 에이전트 시스템)

> **5대 AI 실무팀(리서치팀 · 기획팀 · 감사팀 · 운영팀 · 미디어팀) 및 비서실장 자율 공방 오케스트레이션**  
> 단순 역할극(Roleplay)을 배제하고, 상충 목적함수(KPI) 기반 상호 검증과 구조적 변화량(Diff) 절충을 통해 보고서 품질이 비약적으로 향상됨을 증명하는 의사결정 보좌 시스템

---

## 🔒 기존 레포지토리 100% 안전 연동 원칙 (Read-Only Zero-Touch)

본 시스템은 기존에 구축된 2대 핵심 깃허브 자산의 소스코드나 구글 시트 원본 데이터를 **단 1바이트도 수정·삭제하지 않고 오직 읽기 전용(`GET`)으로만 참조**합니다.

1. **`ai_news_briefing` (외부 레이더):** 일일 뉴스(`AI요약`, `중요도`) 및 `Briefing_Docs` 탭의 서울신용보증재단 업무 인사이트 리포트(`economic_trend`, `implication`) 조회
2. **`meeting_copilot` (내부 나침반):** 5열 표준 지식 DB(`[title | category | summary | keywords | fullText]`)에서 1차 메타데이터(`summary`, `keywords`) 스캔 후 과업과 직결된 핵심 문서 원문(`fullText`)만 핀셋 로드 (토큰 85~90% 절감)

## 📁 프로젝트 디렉토리 구조

```text
total-agent/
├── README.md                      # 시스템 아키텍처 및 품질 선순환 가이드
├── config.py                      # Read-Only 연동 URL, 실행 모드(평시/실전), 팀별 모델 설정
├── main.py                        # 5단계 자율 공방 파이프라인 실행 진입점
│
├── prompts/                       # 5대 팀 + 비서실장 상시 업무 지침서 (Input-Output Contract 명시)
│   ├── chief_secretary.md         # 🎯 비서실장 (구조적 Diff 절충, Plan B/C, Decision Log 지침)
│   ├── team_research.md           # 🔍 리서치팀 (뉴스비서+미팅코파일럿 2단계 메타데이터 탐색 지침)
│   ├── team_planning.md           # 💡 기획팀 (공격적 Plan A 발제 지침)
│   ├── team_audit.md              # 🛡️ 감사팀 (대위변제율·규정·시의회 감사 반박 및 Hard Constraints 지침)
│   ├── team_operations.md         # ⚙️ 운영팀 (창구 부하 진단 및 비대면 패스트트랙 대안 지침)
│   └── team_media.md              # 📑 미디어팀 (공공기관 개조식 □,○,-,• 및 전후 수치 대조 DoD 규격)
│
├── connectors/                    # 기구축 레포지토리 읽기 전용(Read-Only) 어댑터 및 보안 모듈
│   ├── news_client.py             # ai_news_briefing GAS JSON 조회 클라이언트
│   ├── meeting_client.py          # meeting_copilot 5열 지식DB 2단계 스캔 클라이언트
│   └── ci_masker.py               # 로컬 개인/기업 식별정보(사업자번호, 상호 등) 비식별화 엔진
│
├── agents/                        # 멀티 에이전트 오케스트레이션 코어
│   ├── llm_router.py              # 팀별 지침서 로드 및 평시/실전 LLM 라우팅
│   └── engine.py                  # Phase 1~5 자율 공방 및 품질 선순환(Plan A ➔ Plan B) 엔진
│
├── web/                           # 센터장 집무용 통합 웹 대시보드
│   └── index.html                 # 5대 팀 공방 타임라인 + 4종 산출물 탭 뷰어 + A4 인쇄
│
└── outputs/                       # 생성된 결재용 보고서 자동 저장 폴더 (total-agent 내부 전용)
```
